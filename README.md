# 喃言 · Nanyan

> 有些话，轻轻说。

面向挚友与恋人的一对一双人私密情绪空间。弱化即时通讯"必须秒回"的压力，提供异步、低压力的情绪表达，并内置体面退场机制。不做群聊、不做社交广场、不做点赞评论。

## 运行方式

纯前端实现，无需后端、无需构建。直接用浏览器打开 `index.html` 即可使用。

- 推荐使用 Chrome / Edge 最新版。
- 海报导出依赖 `html2canvas`（通过 CDN 引入），导出周报海报时需联网首次加载；其余功能完全离线可用。
- 数据全部保存在浏览器的 `localStorage`，清浏览器数据会丢失。
- **图片放置目录（可随时替换）**：
  - `images/logo.png` — 登录页品牌图标（120×120 圆形裁切，缺失则显示纯灰色圆形占位）。
  - `images/avatars/avatar1.png` ~ `images/avatars/avatar7.png` — 共 7 张图片，但**用户可选预设只有 6 个：avatar2.png ~ avatar7.png**；`avatar1.png` 保留给默认搭档「喃呱」专用，注册时不会分配到。

> 提示：新用户注册即获得默认搭档「喃呱」（固定使用 avatar1.png），单人即可体验双人互动全流程；如需测试真人搭档，仍可浏览器多开/无痕窗口注册第二个账号。详见文末「喃呱 · 默认搭档」章节。

## 核心机制

### 登录后默认进入空间

为减少新用户空白的"先选去哪"摩擦，登录/注册后直接进入一个空间：

1. **新用户注册成功后**：从 6 个可选预设（avatar2~7）中随机分配一个（存于用户数据 `avatar.image` 字段，如 `{ image: "avatar3.png" }`，不会分到 avatar1），并自动创建一个默认空间（用户昵称 + "的小窝"，简介"欢迎来到喃言"），直接跳转 `space.html?id=xxx`。
2. **老用户登录后**：
   - 若已有空间，跳转到最近访问过的空间（记录在用户 `lastSpaceId`）。
   - 若没有任何空间，自动创建一个默认空间并进入。
3. **`profile.html`** 从空间页进入：左上角"返回"按钮 / 右上角"设置 → 个人主页 / 切换空间"。
4. **访问 `index.html` 时若已登录**：自动跳转到最近空间。

### 数据持久化

所有数据存于浏览器 `localStorage`，key 统一使用 `nanyan_` 前缀：

| Key | 含义 |
| --- | --- |
| `nanyan_users` | 全部用户数据（账号、密码哈希、昵称、`avatar: { image } \| { custom: base64 }`、`lastSpaceId`；含一条 `isNangua:true` 的喃呱伪用户） |
| `nanyan_session` | 当前登录态（仅存用户名，登出时设为 `null`） |
| `nanyan_spaces` | 全部空间数据（成员、`bubbles[].comments[]`、密语、邀约、日历、周报、申请、`onboardStep` 教学进度） |

每条泡泡的存储结构（节选）：

```js
{
  id: 'b_xxx',
  author: 'lin',
  text: '今天天气真好',
  emotion: 'happy',          // null / uncomfy / unhappy / meh / blessed / happy / excited
  isPrivate: false,          // true 时仅自己可见，不出现在泡泡池
  image: null,               // 或压缩后的 dataURL
  comments: [                // 泡泡下的留言数组
    { id: 'c_xxx', author: 'yu', text: '我也觉得！', createdAt: 1700000000000 }
  ],
  createdAt: 1700000000000,  // 24 小时限时：非当天的泡泡在页面加载时自动清理
  updatedAt: 1700000000000
}
```

邀约数据结构（存于空间数据的 `invitations` 数组中）：

```js
{
  id: 'inv_xxx',
  type: 'flower',            // 'flower' | 'card' | 'chat'
  fromUsername: 'lin',
  toUsername: 'yu',
  message: '今天看到一朵很好看的花，想送你',
  status: 'pending',         // 'pending' | 'accepted' | 'rejected'
  createdAt: 1700000000000,
  respondedAt: null          // 接受/拒绝时写入时间戳
}
```

### 跨标签页实时同步

`space.html` 与 `profile.html` 均监听 `window` 的 `storage` 事件。当**其他标签页**修改了 `nanyan_` 前缀的 localStorage 项时，当前页面自动重渲染：

- A 发泡泡 / A 在泡泡下留言 / A 发密语 / A 发邀约 → 打开同一空间的 B 标签页会立刻看到（无需刷新）。
- 个人主页监听到 `nanyan_users` / `nanyan_spaces` 变更 → 刷新头像、昵称、空间列表红点。
- 一方退出登录 → 另一方若同浏览器不同账号不受影响；同账号的另一标签页会自动跳回登录页。

## 核心功能

### 1. 头像系统（6 预设图片 + 喃呱专用）

- `images/avatars/avatar1.png` ~ `avatar7.png` 共 7 张图片，但**用户可选预设只有 6 个：avatar2.png ~ avatar7.png**；`avatar1.png` 保留给默认搭档「喃呱」专用。
- **注册时**自动从 6 个预设中随机分配一个存入 `avatar.image`（不会分配到 avatar1）。
- **喃呱固定使用 avatar1.png**（不再用 SVG 青蛙头像）；每次加载都会强制刷新喃呱的 `avatar` 字段为 `{ image: "avatar1.png" }`，保证旧数据升级。
- 所有头像渲染统一走 `<img src="images/avatars/xxx.png">`，圆形裁切；若图片加载失败则**降级为灰色圆形占位 + 首字母**（在 `avatarSvg` 中用 `onerror` 切换，避免裂图）。
- **编辑形象**：6 格缩略图选择器（带随机按钮 + 自定义上传），保存后覆盖 `avatar.image`；喃呱的头像不可编辑。
- 出现位置：个人主页头部、空间头部双人头像、泡泡卡片/留言条、漂浮泡泡边缘小头像、日历情绪对比区等。

### 2. 漂浮泡泡互动（24 小时限时动态）

原"泡泡列表卡片流"改为漂浮泡泡池：

1. **24 小时限时**：泡泡为当日发布的情绪碎片，**次日清零**。页面加载与每次切到「泡泡」Tab 时，会自动清理 `createdAt` 不属于当天的泡泡，泡泡池次日为空，显示"今天还没有泡泡，写下第一颗吧"。

2. **视觉**：
   - 空间页"泡泡" Tab 内容区是一块占满的「泡泡池」渐变背景区。
   - 每条共享泡泡渲染为 80–140px 圆形气泡，位置/大小随机，CSS `@keyframes floatBubble` 做 5–10s 缓动上下漂浮（每条独立速度/延迟）。
   - 泡泡颜色按发布者选择的情绪映射为 6 种柔和背景色（沿用 `EMOTIONS.color`）。
   - 泡泡边缘贴发布者小头像，泡泡中央显示**情绪图标**（不显示文字，保持未知感）。
   - **私密泡泡不进入池**，仅作者本人可通过"我的私密泡泡"入口查看列表。
   - 有新留言的泡泡右上角加一个小红点（`has-new` 类）。

3. **戳开交互**：
   - 点击任意漂浮泡泡 → 底部弹出详情弹窗：情绪条、文字内容、图片、发布者/时间。
   - 弹窗下方显示留言列表，任何人（空间双方）可输入发送；发送后立刻刷新列表并写回 `bubbles[].comments`。
   - **留言输入行**：输入框占大部分宽度（`flex:1`，最小高度 40px）+ 右侧固定 60px 宽"发送"按钮，同一行 `flex` 布局；不再是"输入框短、按钮长"。
   - 作者本人可在弹窗顶部「编辑 / 删除」泡泡。
   - 关闭弹窗后泡泡继续在池中漂浮。

4. **发布泡泡**：保留底部"写个泡泡"按钮 → 弹窗填写（选情绪 / 200 字内文字 / 图片选填 / 私密勾选）→ 发布后立刻在池子里出现。

5. **空状态**：没有泡泡时显示插画 + "今天还没有泡泡，写下第一颗吧"，不出现漂浮动画。

### 3. 密语（留言板式持久聊天）

- 属性：留言板式普通聊天，**持久保存，不过期**。
- 列表：每条密语左侧显示留言者头像（36px 圆形），右侧显示昵称 + 时间 + 内容；自己和对方的消息左右分列（`msg.mine` 右对齐紫色气泡）。
- 输入区：textarea（最小 80px，可自动增高至最多 4 行，约 140px 上限）+ 下方右对齐"发送"按钮；placeholder "写点什么留给TA…"；输入为空时按钮置灰。
- 系统提示：当「聊一聊邀请」被对方接受时，密语列表会自动追加一条居中显示的系统提示气泡"已开启深度对话"。
- 发送后清空输入框，新消息出现在列表底部并自动滚动到底。

### 4. 邀约（送花 / 兑现卡 / 聊一聊邀请）

整体布局：上方历史邀约列表（按时间倒序），下方三个横排等宽操作按钮。

- **三个底部按钮**：送花 | 兑现卡 | 聊一聊邀请，各自弹窗填写附言后发送。
  - 送花弹窗：标题"送出鲜花心意"，placeholder "写下想附带说的话（选填）"，按钮【取消】｜【发送送花邀约】。
  - 兑现卡弹窗：标题"发起兑现卡"，placeholder "填写想要对方完成的心愿"，辅助小字"例：陪我散步、一次拥抱"，按钮【取消】｜【发送兑现卡邀约】。
  - 聊一聊邀请弹窗：标题"发起聊一聊邀请"，placeholder "想和对方聊聊的话题（选填）"，辅助小字"邀请对方开启一次深度对话"，按钮【取消】｜【发送聊天邀约】。

- **历史邀约列表**：每条卡片显示类型图标 + 名称、发起人、附言、时间、状态标签（待处理-橙 / 已接受-绿 / 已拒绝-灰）。
- **接收方操作**：若接收方是当前用户且状态为 pending，卡片底部显示【拒绝】【接受】两个按钮。
- **对方收到邀约时的提示文案**（在卡片中以斜体小字显示）：
  - 送花："XX 向你送出一束鲜花"
  - 兑现卡："XX 向你发来一张兑现卡心愿"
  - 聊一聊："XX 邀请你来一次深度对话"
- **跳转规则**：
  - 聊一聊邀请被接受 → 自动跳转到「密语」Tab，并显示系统提示"已开启深度对话"。
  - 送花、兑现卡接受后 → 仅在列表中留存记录，不跳转。
- **限制**：同一类型邀约在 pending 状态未处理时，不能重复发送同类型邀约（Toast 提示"对方还有未处理的邀约"）。
- **全屏特效（送花 / 兑现卡 / 聊一聊接受时触发）**：
  - 遮罩层挂在 `.app` 容器内（`position:absolute`），**只在手机容器范围内居中**，不覆盖整个浏览器窗口；PC 端居中卡片之外仍是桌面背景。
  - 特效图最大宽度 80%、最大高度 70vh，`object-fit:contain`，完整显示不出画。
  - 动画：0.8→1 缩放 + 淡入（0.25s）→ 停留 2.5s → 淡出 + 轻微放大（0.25s），总时长约 3s。
  - **图片必须为透明底 PNG**（`images/effects/flower.png`、`card.png`、`chat.png`）；代码不对图片做白底处理，若为白底图需用户自行替换为透明底 PNG，缺失时降级为渐变 + 文字卡片。

### 5. 日历（修复点击无法选情绪）

- 月视图格子：**日期数字下方并排显示情绪图标** — 左边是我当天标记的，右边是搭档当天标记的；未标记则不显示。
- **点击任意日期格子 → 弹出当日详情弹窗**（不再在下方展开，避免遮挡）：
  - 顶部显示双方头像 + 当前情绪标记对比。
  - "我的心情"区横排 6 个情绪表情：**等宽等高（52×64px），图标统一 32×32px，名称 11px**，点击选中高亮（淡紫背景 + 主色边框），再次点击同一个可取消；选择后**自动写入空间数据，无需额外保存按钮**，同时弹窗 UI 与日历格子立刻同步刷新。
  - 只能修改自己的情绪，搭档的仅显示不可交互。
  - 底部列出当天的共享泡泡卡片，**点击卡片直接戳开该泡泡**的留言互动弹窗。

### 6. 情绪周报

- 周统计（情绪泡泡 / 密语 / 邀约 / 轻声次数）+ 可编辑模板文案 + `html2canvas` 导出海报 + 历史周报回看。

### 7. 体面退场

- 受邀成员退出空间（仅清除自己的数据）、创建者一键清空全部数据（需输入"清空"二次确认）。

## 视觉与交互

- 主色雾紫 `#9B8EC4`，背景暖白 `#FAF7F5`，卡片白圆角 16px，危险红 `#D4888E`。
- 动效柔和，0.25s 过渡；移动端优先，PC 端居中显示手机宽度容器。
- 所有操作有 Toast 提示，危险操作有确认弹窗；空状态有友好文案 + 表情插画。
- 全程不出现系统 emoji，所有情绪/功能图标/头像占位均为原创 SVG 或 `<img>`（含降级占位）。

## 原创 SVG 情绪（不使用系统 emoji）

统一圆形脸蛋风格，6 个情绪：
1. **难受 `uncomfy`** — 螺旋眼 + 波浪嘴 + 汗珠
2. **不开心 `unhappy`** — 垂眼 + 皱眉 + 下弯嘴
3. **没表情 `meh`** — 圆点眼 + 平嘴
4. **幸福 `blessed`** — 弯月笑眼 + 腮红 + 微笑
5. **开心 `happy`** — 圆点眼 + 大笑嘴
6. **激动 `excited`** — 星星眼 + 张嘴 + 激动线

## 自测流程（本轮改动后必走）

### A. 单账号新注册 + 头像随机
1. 清 localStorage（Application 面板）或无痕窗口，打开 `index.html`。
2. 注册账号 A（用户名/昵称/密码），应自动跳转到默认空间。
3. 点"返回"进 `profile.html`，个人主页头像应为 `avatar2~7` 中某一张（图片圆形裁切，不会是 avatar1）；若图片缺失则是灰色圆 + 首字母。
4. 进入空间，空间头部双人头像应正确显示 A 的图片头像 + 喃呱的 avatar1.png；点"编辑形象"弹窗应为 **6 格缩略图（avatar2~7，不含 avatar1）**，切换选中 / 随机按钮（不会抽到 avatar1） / 保存后立即刷新到新头像。
5. **功能宫格**：profile.html 的 `.grid-fns` 左右各留白 20px，卡片间距 14px，不贴手机容器边框。

### B. 漂浮泡泡 + 戳开 + 留言 + 24h 限时
1. 在空间"泡泡"Tab 点「写个泡泡」→ 选情绪、写 20-100 字、不勾私密 → 发布。
2. 泡泡池中应出现一个对应颜色的气泡，缓慢漂浮；边缘有发布者头像小圈，中心有情绪图标。
3. **点击泡泡**弹出详情弹窗：文字、发布者、时间、情绪正确；底部可输入留言，发送后列表立刻显示（含留言者头像/昵称/时间）。
4. 有留言的泡泡关闭弹窗后，边缘应显示红色小点。
5. 再发一条「私密」泡泡 → 泡泡池里不出现；但下方出现「我的私密泡泡（1）」入口，点开可编辑/删除。
6. **24 小时机制**：手动改一条泡泡的 `createdAt` 为昨天（Application 面板编辑 `nanyan_spaces`），刷新页面 → 该泡泡应被自动清理，泡泡池显示"今天还没有泡泡，写下第一颗吧"。

### C. 双人 + 双标签页实时同步（关键）
1. 在账号 A 空间页复制邀请码。
2. **同浏览器另开一个标签页**（或无痕窗口）注册账号 B，回到主页「加入空间」输入 A 的邀请码 → A 同意。
3. 双方都在同一空间页（两个标签页）：
   - **A 发一条共享泡泡** → B 的标签页应自动重渲染泡泡池，看到新泡泡。
   - **A 在泡泡下写留言** → B 的标签页若已戳开该泡泡，自动重新读取空间并在留言列表看到；若只在泡泡池，泡泡边缘的小红点立刻出现。
   - **A 在密语 Tab 发一条密语** → B 的密语 Tab 红点立刻出现，切进去能看到新消息。
   - **A 发一个送花邀约** → B 的邀约 Tab 红点立刻出现，切进去能看到待处理卡片，可接受/拒绝。
   - **A 在日历里标记今天情绪** → B 切换到日历 Tab，今天格子立刻出现两个并排情绪图标（自己的 / A 的）；B 也点该日期 → 弹窗里可看到 A 的情绪（但不可改），B 自己可点 6 个表情切换/取消。
4. 任一标签页退出登录 → 其他标签页自动跳回登录页。

### D. 日历点击 + 情绪选择 + 泡泡联动
1. 在日历 Tab 点任意过去的日期 → 弹出「当日详情」。
2. 点击横排 6 个情绪中的「开心」→ 选中高亮（淡紫背景 + 主色边框）+ Toast「已标记情绪」→ 日历格子下方日期下立刻出现开心小图标。
3. 再点同一个「开心」→ 取消高亮 + Toast「已取消标记」→ 格子图标消失。
4. **6 个情绪选项必须等宽等高（52×64px），图标统一 32×32px（含"难受"），名称 11px 居中在图标下方**。
5. 若该日期有泡泡，点击泡泡卡片会关闭详情弹窗，随后打开泡泡戳开弹窗（可继续留言）。

### E. 密语 + 邀约完整流程
1. A 在密语 Tab 发一条密语 → B 密语 Tab 看到新消息，含 36px 头像 + 昵称 + 时间 + 内容。
2. 密语输入框为 textarea，最小 80px 高，可自动增高至最多 4 行；placeholder "写点什么留给TA…"；输入为空时发送按钮置灰。
3. A 在邀约 Tab 点「送花」→ 弹窗填写附言 → 发送 → 邀约列表出现一条 pending 卡片。
4. B 的邀约 Tab 看到该卡片，底部有【拒绝】【接受】按钮；点【接受】→ 状态变"已接受"（绿色），留存记录，不跳转。
5. A 再发「兑现卡」邀约 → B 接受 → 同样留存记录，不跳转。
6. A 发「聊一聊邀请」→ B 接受 → **自动跳转到密语 Tab**，并显示一条居中系统提示"已开启深度对话"。
7. A 再次发同类型邀约且上一条仍 pending → Toast 提示"对方还有未处理的邀约"，无法重复发送。

### F. 图片缺失降级
1. 临时重命名 `images/logo.png` 为 `_logo.png` → 刷新 `index.html`，品牌区应显示 120×120 灰色圆形，不出现裂图或任何文字 logo。
2. 临时重命名 `images/avatars/avatar3.png` → 页面上任何使用 avatar3 的位置应自动降级为"灰色圆 + 首字母"，无裂图。

## 常见问题

- **问：为什么 `storage` 事件有时不触发？**  
  答：Chrome/Edge 的 `storage` 事件**只在"其他"标签页触发**（即修改 localStorage 的那个当前标签页不会收到）。所以双标签同步需两个标签页互操作。

- **问：图片存 base64 DataURL 会不会撑爆 localStorage？**  
  答：泡泡发布时图片会压缩到 ≤480px 宽 / 0.72 JPEG 质量（约 60-180KB），localStorage 通常 5MB，建议本地演示阶段控制图片数量。

- **问：升级旧用户数据（从像素小人配色 → 6 预设图片）？**  
  答：`avatarSvg` 会对旧格式 `{ skin, hair, clothes }` 自动取 skin 颜色哈希后映射到 6 个可选预设之一（avatar2~7，不会选到 avatar1）；喃呱固定使用 avatar1.png，每次加载 `seedNangua` 强制刷新。

## 喃呱 · 默认搭档（教学 bot）

新用户注册成功即获得一个默认搭档「喃呱」（固定使用 `avatar1.png` 头像）。喃呱是真正的空间成员，所有互动功能都可直接体验，无需另开标签页或注册第二个账号。

> 定位：默认空间一旦创建，**始终满员（用户 + 喃呱）**，邀请码加入会提示"空间已满员"。若要邀请真人，需先在空间「设置」中移除喃呱；移除后所有喃呱自动互动（欢迎、自动回复、自动接受等）失效，需真人搭档才能继续互动。

### 一、注册即默认好友

1. 新用户注册成功 → 自动创建默认空间（昵称 + "的小窝"）。
2. **喃呱直接写入空间的 `members` 数组**，从这一刻起就是正式成员，互动功能可用。
3. 同时生成一条 `pending` 状态的加入申请记录（仅用于新手教学展示），个人主页「待处理申请」显示红点。
4. **关键点：无论用户对这条申请点同意还是拒绝，喃呱始终是空间成员，不会被移除。**

### 二、申请处理流程（纯教学）

1. 注册后进入个人主页，页面中间弹出第 0 步引导弹窗（喃呱头像 + "你有一条新的好友申请哦～"），点【下一步】后高亮「待处理申请」按钮（呼吸边框）。
2. 点开申请列表，看到喃呱的申请："你好呀，我是喃呱，能加入你的空间吗？"
3. 点「同意」→ 申请状态变 `approved` → 自动弹出第 1 步引导弹窗。
4. 点「婉拒」→ 申请状态变 `rejected`，但喃呱仍在空间里；2 秒后喃呱自动重新发起一条 `pending` 申请（红点再次出现），直到用户点同意为止。

### 三、新手教学（弹窗分步引导，共 7 步）

移除原来的顶部引导条，改为**页面中间弹窗分步引导**。进度存于空间数据 `onboardStep` 字段（0~6 进行中，7 已完成）。

弹窗样式：页面正中间，白底圆角 20px，宽度 80%（最大 320px），柔和阴影；顶部喃呱圆形头像，中间提示文字，底部【下一步】主色按钮；弹窗出现时背景加半透明遮罩禁止其他操作；右上角有"跳过引导"文字按钮（点击直接结束全部引导）。点【下一步】后遮罩消失，只保留目标元素高亮（2px 主色描边 + 呼吸动画）；目标元素会自动滚动到视区。

引导步骤（每步完成后自动进入下一步，无需手动点"完成"）：

| 步骤 | 所在页 | 提示 | 高亮目标 | 完成检测 |
| --- | --- | --- | --- | --- |
| 0 | 个人主页 | "你有一条新的好友申请哦～点击下方的「待处理申请」" | 待处理申请按钮 | 用户点同意喃呱申请 |
| 1 | 个人主页 | "太好了！现在点击空间卡片，进入你和喃呱的小天地吧" | 空间卡片 | 用户点击空间卡片进入空间 |
| 2 | 空间 | "先试试发一颗泡泡吧～点底部的「写个泡泡」按钮" | 写个泡泡按钮 | 用户发布首颗公开泡泡（喃呱自动回一颗） |
| 3 | 空间 | "来密语 Tab 说句话吧，喃呱会回复你的" | 密语 Tab | 用户发首条密语（喃呱 2-4s 自动回复） |
| 4 | 空间 | "去邀约 Tab 送喃呱一束花吧，有惊喜特效哦" | 邀约 Tab | 用户发送花邀约（喃呱自动接受 + 全屏特效） |
| 5 | 空间 | "最后去日历 Tab 标记一下今天的心情吧" | 日历 Tab | 用户在日历标记任意情绪 |
| 6 | 空间 | "恭喜你学会啦！现在点左上角返回…" | —（无高亮） | 用户点【完成】→ 标记完成 |

- 用户中途离开再回来，进度保留（`onboardStep`），从当前步继续。
- 已完成引导（`onboardStep = 7`）的用户不再触发。
- 空间页加载时若 `onboardStep = 1`（个人主页"进入空间"完成）会自动推进到第 2 步并弹窗。

### 四、喃呱互动入口

1. **空间头部喃呱头像可点击**（带绿点标识），点击弹出"找喃呱玩"菜单，7 项：
   - 让喃呱发颗泡泡
   - 让喃呱说句话
   - 让喃呱送我花
   - 让喃呱发兑现卡
   - 让喃呱邀我聊一聊
   - 让喃呱接受我最新邀约
   - 让喃呱拒绝我最新邀约
2. **喃呱自动回应**（无需手动触发）：
   - 用户发密语后 2-4 秒随机回复一条
   - 用户发送花邀约后约 3.5 秒自动接受并播放送花特效

### 五、移除喃呱

- 空间创建者在「设置」底部可见「移除喃呱（之后可邀请真人）」按钮。
- 点击后清空喃呱在该空间产生的所有内容（消息、泡泡、邀约），喃呱从 `members` 移除，空间恢复为单人状态。
- 移除后可通过邀请码邀请真人搭档加入。
- 喃呱被移除后，所有自动回应、菜单互动均失效，需要真人搭档才能继续互动。

  }],

### 推荐单人快速自测流

1. 清 localStorage 或开无痕窗口，打开 `index.html` 注册账号 A。
2. 注册后自动跳转到默认空间（空间头部右侧出现喃呱 avatar1.png 头像）；点浏览器"返回"回到 `profile.html`，页面中间应弹出第 0 步引导弹窗，点【下一步】后「待处理申请」按钮出现呼吸高亮。
3. 点「待处理申请」→ 看到喃呱的 pending 申请：
   - 点「婉拒」→ 2 秒后喃呱自动重发，红点再次出现。
   - 点「同意」→ 弹出第 1 步引导弹窗，点【下一步】后首张空间卡片高亮。
4. 点击空间卡片进入空间页，自动弹出第 2 步引导（发泡泡）。依次完成 7 步引导：发泡泡（喃呱回一颗）→ 写密语（喃呱回复）→ 送花（喃呱接受 + 全屏特效，特效应限定在手机容器内居中）→ 标记日历心情 → 点【完成】。
5. 引导结束后，点空间头部喃呱头像 → 测试菜单 7 项互动。
6. 进「设置」→「移除喃呱」→ 空间恢复单人状态，喃呱头像消失，菜单失效，可再用邀请码邀请真人。
